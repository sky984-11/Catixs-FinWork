# 项目看板功能说明

项目看板用于跟踪客户或供应商项目从规划、进行、验收到完成的全过程。它把项目负责人、客户或供应商、进度、ETA、子任务、讨论、文件和飞书提醒集中到一个页面，适合日常项目推进和早会同步。

## 入口

前端菜单进入：`项目看板`

飞书每日总结中的项目标题和子任务标题支持点击跳转：

- 点击项目标题：打开项目详情。
- 点击子任务标题：打开项目详情并定位到对应子任务。

## 看板视图

看板按项目状态分为四列：

- 规划中：还在准备资源、排期或等待启动。
- 进行中：正在实施。
- 验收中：等待客户、内部或交付结果确认。
- 已完成：项目已经结束。

项目卡片上会显示客户、负责人、优先级、健康度、ETA、进度和未完成子任务。鼠标悬浮到项目卡片时，会展示未完成子任务的提示列表，方便快速判断下一步要处理什么。

## 新增项目

点击右上角 `新增项目` 创建项目。

项目表单沿用新增客户的分组样式，分为“基本信息”“交付计划”“预算与说明”，宽屏双列、窄屏单列。表单内容独立滚动，底部保留取消和保存按钮；保存期间禁用重复提交和关闭。

必填字段：

- 项目名称
- 项目类型：客户项目（默认）或供应商项目
- 客户或供应商：根据项目类型选择，不能同时绑定
- 负责人

建议填写：

- 项目编号：用于和合同、订单或内部交付编号对应。
- 合同编号：便于财务和合同追踪。
- 截止日期：用于看板逾期判断和每日总结。
- 项目说明：记录交付范围、特殊要求和关键背景。

客户下拉框支持中文、英文和拼音模糊搜索，并优先展示客户简称，右侧展示签约主体标签。供应商下拉框读取供应商管理中的记录，支持名称、全称、编号及拼音搜索。

新增和编辑项目均可选择项目类型，切换类型后需重新选择客户或供应商。供应商项目在卡片、详情和飞书提醒中显示供应商名称；看板搜索及“客户 / 供应商”筛选支持两类项目。现有客户项目和历史客户关联保持兼容。

## 客户与供应商关联 API

沿用 `/api/v1/project` 路由和现有 token 登录、接口权限校验；查看和编辑还需为项目负责人或共享用户。供应商下拉框沿用 `/api/v1/vendor/list`，需要该接口访问权限。

- `POST /create`：新增 `project_type`（`customer` 或 `vendor`，默认 `customer`）、`vendor_id`（供应商 `Company` ID，`role=2`）。原 `customer_id` 仍为 CRM 客户 ID。
- `POST /update`：新增字段同上，同时传入 `id`；未传类型或供应商字段时保留原关联。切换到供应商项目清除 CRM 和历史客户关联，切换到客户项目清除供应商关联并要求选择客户。
- `GET /list`：新增可选筛选参数 `project_type`、`vendor_id`，原筛选参数不变。
- `GET /get?project_id=123`：详情及上述接口返回项目对象增加 `project_type`、`vendor_id`、`vendor_name`、`vendor_legal_name`，原客户字段保持不变。

供应商项目创建请求示例：

```json
{"name":"供应商线路开通","owner":"负责人用户名","project_type":"vendor","vendor_id":12}
```

成功响应示例（省略其余既有项目字段）：

```json
{"code":200,"msg":"Created Successfully","data":{"id":123,"name":"供应商线路开通","project_type":"vendor","vendor_id":12,"vendor_name":"示例供应商","vendor_legal_name":"示例供应商有限公司","customer_id":null,"legacy_customer_id":null,"customer_name":""}}
```

错误：HTTP 400 表示供应商不存在、记录不是供应商、同时绑定客户和供应商，或切回客户项目未选择客户；HTTP 422 表示类型、ID 等字段格式无效；HTTP 401/403 表示登录或权限校验失败。既有数据库冲突仍沿用响应体 `code=400`。

部署前执行 `aerich upgrade` 应用 `173_20260918020000_project_vendor.py`，增加类型和供应商外键。旧项目自动标记为 `customer`；供应商删除后外键置空，项目类型仍保留为 `vendor`，可重新选择供应商。回滚迁移会移除新增字段及其中保存的供应商关联。

应用启动时也会执行待应用的 Aerich 迁移，再执行 `Tortoise.generate_schemas(safe=True)` 和账单产品模板初始化。此顺序避免旧项目表尚未增加 `project_type` 时，PostgreSQL 生成字段注释报“字段不存在”。更新代码时须同时包含迁移文件；迁移错误会保留并阻止启动，不会通过忽略异常掩盖结构不一致。

## 项目进度

打开项目详情后，可以在概览中拖拽项目进度条调整进度。

进度颜色会随完成度渐变：

- 低进度偏红色，表示刚开始或风险较高。
- 中间进度逐步过渡到橙色、黄色。
- 接近完成时变为绿色。

拖拽后系统会自动保存，无需额外点击保存。

## 子任务

每个项目可以创建多个子任务。子任务用于拆分实际执行动作，例如：

- 确认资源
- 等待供应商回复
- 收发光信息
- Patching
- 客户验收

子任务支持：

- 设置负责人
- 设置 ETA 时间
- 编辑标题、负责人、ETA、备注
- 勾选完成
- 删除
- 回复讨论
- 上传或添加相关文件链接

子任务 ETA 会用于飞书提醒。

## 文件和链接

项目文件支持两种方式：

- 上传本地文件
- 添加外部链接

外部链接适合飞书文档、飞书文件夹、共享盘目录等无法直接上传的资料。链接必须以 `http://` 或 `https://` 开头。

子任务也支持上传文件和添加链接，适合把某个交付动作相关的资料挂在对应任务下面。

## 共享项目

默认情况下：

- 普通用户只能看到自己负责的项目。
- `admin` 可以看到所有项目。

项目卡片上的共享图标可以把项目共享给一个或多个用户。被共享用户可以在自己的项目看板中看到该项目。

适用场景：

- 项目负责人需要让协同人员看到项目。
- 交付、NOC、财务等角色需要共同跟进同一个项目。
- 临时交接项目。

## 飞书提醒

系统支持两类飞书通知。

### 子任务 ETA 提醒

未完成子任务会按 ETA 触发提醒：

- 距离 ETA 还有一天：发送临近到期提醒。
- 到达 ETA：发送到期提醒。

如果项目已经完成或归档，该项目下的子任务不会继续提醒。

如果修改了子任务 ETA，系统会重置该子任务的提醒状态，按新的 ETA 重新判断。

### 每日项目总结

每天早上 8:30，系统会把规划中、进行中、验收中的项目通过 Finwork 飞书应用发送给对应负责人。

每日总结会按负责人分别生成，每个人只收到和自己有关的项目，包括：

- 项目负责人是自己。
- 子任务负责人是自己。
- 项目共享用户包含自己。

负责人需要在系统用户列表中维护手机号。系统会优先用用户手机号调用飞书接口获取 user_id，再通过 Finwork 飞书应用把每日总结、ETA 提醒、新项目和新子任务通知发送给对应人员。

每日总结包含：

- 负责人汇总
- 项目数
- 未完成子任务数
- 按状态分组的项目列表
- 项目编号
- 子任务编号
- 项目 ETA
- 子任务 ETA
- 可点击跳转的项目和子任务链接

### 新项目和新子任务通知

创建新项目或新子任务时，如果负责人和创建人不是同一个人，系统会立即通过 Finwork 飞书应用通知对应负责人。

飞书链接固定使用：

```text
https://finwork.catixs.net
```

## 项目 ETA 提醒

项目本身的截止日期也会触发飞书提醒，规则和子任务 ETA 一致：

- 距离项目 ETA 还有一天：发送项目临近到期提醒给项目负责人。
- 到达项目 ETA：发送项目到期提醒给项目负责人。
- 项目已完成或归档后，不再发送项目 ETA 提醒。
- 修改项目截止日期后，系统会重置提醒状态，并按新的 ETA 重新判断。

## 推荐使用方式

1. 创建项目时先选客户、负责人和状态。
2. 把交付动作拆成子任务，并给每个子任务设置负责人和 ETA。
3. 每天通过看板查看逾期和风险项目。
4. 项目推进时更新进度条和子任务状态。
5. 需要多人协同时，用共享功能把项目共享给对应用户。
6. 项目结束后把状态改为已完成，避免继续产生子任务提醒。

## 常见问题

### 为什么我看不到某个项目？

普通用户只能看到自己负责或被共享的项目。需要项目负责人把项目共享给你，或者由 `admin` 查看。

### 为什么子任务没有飞书提醒？

通常有几种原因：

- 子任务已经完成。
- 项目已经完成或归档。
- 子任务没有设置 ETA。
- Finwork 飞书应用未配置、负责人没有维护手机号、手机号无法匹配飞书用户或发送失败。
- 该子任务已经发送过对应阶段提醒。

### 为什么每日总结里没有某个项目？

每日总结只包含规划中、进行中、验收中的项目，并按负责人分别发送。已完成或归档项目不会进入每日总结；普通用户只会收到自己负责、参与子任务或被共享的相关项目。

### 为什么飞书链接打不开？

确认后端配置中的 `WEB_BASE_URL` 为：

```text
https://finwork.catixs.net
```

修改配置后需要重启后端服务。
