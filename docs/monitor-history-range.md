# 历史事件自定义时间

历史事件页面提供发生时间起止选择，默认近 7 天；修改时间自动查询，自动刷新沿用已选时间范围。列表仍按同一主机、同一触发器合并显示最新记录，双击按同一时间范围查看全部同类记录。事件列表页的同类历史保留默认近 7 天。

`GET /api/v1/monitor-events?history=true&time_from=1794499200&time_till=1794585600`

- `time_from` / `time_till`：可选 Unix 秒，必须成对传入；范围 0 至 4102444800，开始不能晚于结束，仅 `history=true` 可用。不传时兼容原有近 7 天查询，包括通知轮询。
- 查询按告警发生时间筛选，恢复时间不作为筛选条件。实际历史可用范围取决于 Zabbix 事件保留策略。
- 响应沿用 `{code,msg,data}`，`data.rows`、`categories`、`summary`、`truncated` 等结构不变，自定义查询 `scope` 为“已选主机指定时间内发生的问题事件”。`summary` 仍为当前监控状态，不是历史时间段统计。
- 沿用登录及该 GET 接口权限；401/403 为认证/权限错误，422 为时间参数无效。主机和监控项纳管范围仍强制限制查询。
- 单次读取上限仍为 2000 条，超限 `truncated=true`，界面提示记录可能不完整；可缩小时间范围查看。没有把历史查询跨度限制为 7 天；指标历史图的独立时间限制不受此改动影响。
