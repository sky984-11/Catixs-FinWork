# 事件分类自定义字段

分类管理可为每个分类新增字段，包含稳定的英文键和中文显示名称；监控主机编辑弹窗根据分类显示填写项。字段值显示在主机列表、事件列表、同类历史和事件详情，并附在飞书告警/恢复卡片及 AI 分析上下文中。

传输线路在旧配置尚未定义 fields 时，默认提供 `circuit_id`（线路编号）、`provider`（供应商）、`site_a`（A 端位置）、`site_b`（B 端位置）、`bandwidth`（带宽）。不会推测、自动填入实际线路资料；已有字段定义（包括空数组）优先。字段仅在 FinWork 维护，不修改 Zabbix。

## API 兼容扩展

现有 `GET/PUT /api/v1/monitor-events/settings` 保持鉴权及权限要求不变，继续使用 revision 防并发覆盖。分类新增可选 `fields`，主机新增可选 `attributes`：

```json
{
  "revision": 3,
  "categories": [{"key":"transmission","label":"传输线路","fields":[{"key":"provider","label":"供应商"}]}],
  "hosts": [{"hostid":"10081","category":"transmission","itemids":null,"attributes":{"provider":"示例供应商"}}]
}
```

PUT 仍提交完整分类/主机列表，不能仅提交要改的一行。成功返回完整配置及新 revision。字段最多 20 个，键为英文字母开头的 1–40 位英文、数字、下划线或连字符，名称 1–40 字符，同分类键和名称不重复；主机属性值最多 300 字符。无效数据返回 422，版本冲突 409，未登录/无权限沿用 401/403。

旧客户端省略 fields/attributes 时保留已有数据。删除字段、清空字段列表或变更主机分类后保存，清除不属于当前分类的属性；空值不存储。英文键已保存后界面禁止修改，可调整中文名称。

事件列表和详情响应中的 `hosts[].attributes` 为展示数组，例如 `[{"key":"provider","label":"供应商","value":"示例供应商"}]`。仅输出当前分类定义且有值的属性。历史事件展示当前主机属性，不是告警发生时的属性快照；已发送飞书消息不会因后来修改而变化。

飞书卡片每台主机的属性文本最多 2000 字符，最多展示 5 台相关主机；完整属性可查看事件详情。AI 总上下文仍受原长度限制。属性存储在原配置 JSON 中，无数据库表结构调整。
